# Core Loop

## Summary

The parent game is The World Beneath. This page currently documents the **Glassroot Garden World Key subgame loop**, not the full main-game loop.

Glassroot Garden is built around a visible farming and processing loop. The player plants crops, watches growth, uses Companion automation, harvests raw herbs, dries herbs, loads dried herbs into a magitech bundler, and resolves finished bundles into Notice Board contracts or World Key shared storage.

## Memory Items

- Fact - The smallest intended loop is: plant a crop, see it appear, wait, watch a Companion help or fail, harvest, receive a reward, then replant or improve the garden.
- Fact - The implemented full-loop prototype includes planting, Companion tilling/fetching/planting, growth timers, optional action windows, automated harvesting, raw bins, drying rack, dried bins, bundler loading, finished bundle processing, contract completion, and World Key shared storage.
- Fact - A normal browser session is expected to include loading state, resolving offline progress later, scanning ready crops, harvesting, replanting, assigning Companions, watching activity, and leaving growth to continue.
- Decision - World Key bundle outputs must remain separate from directly usable main-game inventory.
