# Player Fantasy

## Summary

Scope: World Key: Glassroot Garden.

The player opens a World Key and enters a hidden magitech garden where symbolic plant-patterns can be cultivated with Companion help. The fantasy is not ordinary farming; it is a controlled, Ledger-readable greenhouse under the World Beneath.

## Memory Items

- Fact - Glassroot Garden should feel like a private greenhouse hidden under ordinary reality, a magitech garden projected through the World Key, and a controlled pattern farm.
- Decision - The UI mood should stay TWB: black glass, cyan/teal tactical frames, yellow-gold status nodes, deep green glow, rootline diagrams, amber alchemical labels, moon/ward glyphs, and old botanical plate silhouettes.
- Decision - Player-facing language should say Companion, not pet, where possible.
- Warning - Do not reduce Companions to "owned animals" language. Companion Cards should feel like bonds, contracts, provenance records, summon patterns, constructs, or captured patterns.
