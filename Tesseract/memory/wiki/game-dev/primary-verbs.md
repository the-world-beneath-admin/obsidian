# Primary Verbs

## Summary

Scope: World Key: Glassroot Garden.

The main player verbs are about choosing, timing, supervising, processing, and claiming. Companions perform much of the physical garden labor.

## Memory Items

- Fact - Primary verbs include open, choose, plant, assign, watch, click, harvest, dry, load, bundle, fulfill, transfer, and improve.
- Fact - Required farm labor is Companion-driven: till, fetch seed, plant, harvest, and carry to storage.
- Fact - Player-timed optional actions happen during growth windows and can influence yield.
- Fact - Processing verbs include moving raw herbs to the drying rack, loading dried herbs into the Bundler in recipe order, creating a finished bundle, and resolving that bundle to a contract or shared storage.
