# Current Mechanics

## Summary

This page currently documents **Glassroot Garden**, a World Key subgame prototype. It does not describe the full main-game mechanics of The World Beneath.

For main-game systems, use [[main-game-systems]].

## Memory Items

- Fact - Already working or partly working: Seed Bag, seed-to-plot interaction, Companion tilling/fetching/planting, crop timers, optional action windows, optional action success/failure, yield changes, Companion harvesting, raw bins, Storage Hut / Herbalist Workbench, visual Notice Board recipes, Transfer Bundle selection, and Bundler panel.
- Fact - Verified full loop: plant crops, trigger optional work, harvest raw herbs, dry herbs, move dried herbs into bins, load Bundler in recipe order, create Greenward Order, and resolve it for Gardening Tokens and Board XP.
- Fact - Not yet working in that source plan: persistent Cloudflare account/database integration, server-authoritative World Key shared storage, server-side generated/rotated Notice Board contracts, and reusable checked-in automated regression command.
- Fact - Transfer bundles move output to World Key shared storage and do not pay Notice Board tokens or Board XP.
