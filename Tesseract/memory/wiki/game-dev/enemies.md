## Summary

Scope: World Key: Glassroot Garden.

There are no combat enemies defined for Glassroot Garden memory yet. The closest current design equivalent is risk, mishap, pest clearing, Companion failure, crop instability, and inventory overflow.

## Memory Items

- Fact - The MVP should not include crop death. Failures should delay, reduce quality, skip bonuses, or create harmless misbehavior.
- Fact - Companion failure examples include overwatering, tending the wrong plot, getting startled, napping, harvest fumbles, and weaker warding.
- Hypothesis - Pest clearing can function as a soft farming hazard system without becoming combat.
- Open Question - Should this page remain a soft-hazards page for Glassroot Garden, or should a separate `hazards.md` replace it later?
