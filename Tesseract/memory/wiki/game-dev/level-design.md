# Level Design

## Summary

Scope: World Key: Glassroot Garden.

The current level design is a compact browser farm plus a focused Storage Hut / workbench processing screen. The farm should be readable, not sprawling; the workbench should feel like a functional alchemical station.

## Memory Items

- Decision - Start with one farm screen and 24 usable plots.
- Decision - Use a Stardew-like angled top-down 2D layout, not true 3D or full isometric.
- Fact - MVP map recommendation: center crop plots, left Companion slots/resting pads, top World Key status header, right selected plot panel, bottom crop drawer and action controls.
- Decision - The Storage Hut should read as a compact herbalist/alchemical workbench instead of a full-room hut interior with oversized shelves.
- Decision - Raw/dried plant bins belong in the left workbench module, finished bundles in the right module, and processing surface in the center.
