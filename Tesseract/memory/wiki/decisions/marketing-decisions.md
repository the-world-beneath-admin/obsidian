# Marketing Decisions

## Active Decisions

- Decision - 2026-05-11 - Treat The World Beneath main game as the default marketing scope.
  - Reason: The user clarified that Glassroot Garden is a subgame, and the public TWB website positions the main game as the flagship shared-world RPG.
  - Source: User clarification - 2026-05-11.
  - Source: [[memory/raw/keyword-research/2026-05-11-main-game-seo-seed-sources]]
- Decision - 2026-05-11 - Keep World Key/subgame marketing separate from main-game marketing.
  - Reason: Subgame mechanics and keywords can distort the parent game positioning if merged.
  - Source: [[memory/wiki/game-dev/project-hierarchy]]
- Decision - 2026-05-11 - Lead main-game positioning with the concrete RPG loop first, then frame it as a shared-world RPG.
  - Reason: User approved the positioning pilot recommendation. This makes the main game legible to cold players before widening into societies, trade, territory pressure, community, and account identity.
  - Approved Working Pitch: The World Beneath is a shared-world RPG where dungeon runs feed creature growth, crafting, inventory progression, and a larger hidden world shaped by player societies.
  - Source: User approval - 2026-05-11.
  - Source: [[memory/reports/marketing/2026-05-11-main-game-positioning-pilot]]
- Decision - 2026-05-11 - Make playable World Keys the primary landing-page CTA once they are ready.
  - Reason: The first two World Keys are expected to be the first player-facing ready game products in the world. The landing page should offer play-now value while the full game is still in development.
  - Landing Direction: Play the World Keys now while you wait for the full game.
  - Source: User direction - 2026-05-11.
  - Source: [[memory/wiki/marketing/landing-page-strategy]]
- Decision - 2026-05-11 - Use The Garden and The Alchemy Lab as the first public free World Key names.
  - Reason: User clarified that Glassroot Garden is not the public name; the player names their own garden when opening The Garden, and names their own lab when opening The Alchemy Lab.
  - Source: User clarification - 2026-05-11.
  - Source: [[memory/wiki/launch/first-two-world-keys-release-briefs]]
