# World Keys Overview

## Summary

World Keys are browser-accessible subgame experiences connected to The World Beneath. They can share umbrella inventory and pet concepts, but each World Key remains its own bounded mini-game with its own implementation lane.

## Current Public World Keys

- The Garden: farming/garden World Key, active source project `C:\Users\yrred\Desktop\Unity\TWB-Farming`.
- The Alchemy Lab: alchemy/cave-gathering World Key, active source project `C:\Users\yrred\Desktop\Unity\TWB-Alchemy`.

## Rules

- World Keys are not the main Unity game.
- Do not let World Key mechanics overwrite main-game design decisions.
- Shared inventory and pets are umbrella concepts, but production authority eventually needs a real account/service backend rather than local browser storage.
- Browser clients are untrusted; production rewards, inventory grants, Companion/pet locks, and cross-World-Key transfers need server/account authority before launch.
