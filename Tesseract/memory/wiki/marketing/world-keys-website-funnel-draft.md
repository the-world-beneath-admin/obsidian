# World Keys Website Funnel Draft

## Status

Source edit pass applied - 2026-05-11. Deployment not approved or performed.

## Purpose

Reframe the public site so visitors land on a clear play-now path:

> Play The Garden and The Alchemy Lab while The World Beneath grows.

This draft is for the homepage and World Keys page. It does not change website source yet.

Source update report: [[reports/marketing/2026-05-11-world-keys-prelive-source-update]]

## Current Site Context

- Homepage currently leads with the main-game positioning:
  - `Run dungeons. Grow creatures. Shape the world beneath.`
  - `Follow development, join the community, and help shape what comes next.`
- Homepage currently treats book/audiobook as a prominent lore gateway.
- Homepage currently links to World Keys near the lower ecosystem section.
- World Keys page currently says no public World Key game is live and that the previous pilot has been retired.

## Funnel Priority

1. Play the first free World Keys.
2. Follow or register for The World Beneath.
3. Read or listen deeper into the story.
4. Follow Steam or Kickstarter when those pages are ready.

## Important Gate

Use the **play-now** copy only when at least one World Key is actually playable from the site or itch.io.

If the builds or itch.io pages are not public yet, use the **pre-live** copy. Do not invite visitors to "play now" unless they can actually play.
