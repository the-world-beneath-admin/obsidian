# Positioning

## Summary

This page covers **The World Beneath main-game positioning**. Glassroot Garden positioning is preserved separately in [[glassroot-positioning]].

## Memory Items

- Signal - Public copy frames The World Beneath as a shared-world RPG with dungeon runs, creature growth, crafting, inventory, societies, trade, territory pressure, and community/account identity.
- Decision - Lead with the concrete RPG loop first, then use shared-world RPG as the larger frame.
- Decision - Approved working pitch: The World Beneath is a shared-world RPG where dungeon runs feed creature growth, crafting, inventory progression, and a larger hidden world shaped by player societies.
- Hypothesis - Shorter copy can use: Run dungeons, grow strange creatures, craft stronger paths forward, and help shape a shared world beneath the ordinary one.
- Hypothesis - Differentiator: The project combines game systems, live community, account identity, and lore gateways while the world is still forming.
- Warning - Avoid sounding like a lore project with a game someday; the public game page already says the game systems are the center.
- Warning - Avoid promising MMO-scale systems until the product lane explicitly supports that.
