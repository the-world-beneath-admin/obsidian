# SEO Strategy

## Summary

Use SEO to connect The World Beneath main game to player search intent around shared-world RPGs, dungeon RPGs, creature collectors, crafting/progression RPGs, and community-led game development. Glassroot-specific SEO lives in [[glassroot-seo-strategy]].

## Memory Items

- Decision - Future meaningful SEO research should follow [[seo-research-workflow]] and produce a report under `memory/reports/seo/` before permanent memory changes.
- Hypothesis - Primary search intent: players looking for dungeon RPGs, creature collection/growth, crafting RPGs, and long-term progression.
- Hypothesis - Secondary search intent: players interested in shared worlds, community RPGs, lore-rich fantasy, and account-based game ecosystems.
- Hypothesis - Store-page/site SEO should combine concrete mechanics with the broader world: "dungeon RPG" + "creature growth" + "crafting" + "shared world".
- Warning - Do not rely on "shared-world RPG" alone; it needs concrete verbs and systems nearby.
- Warning - Do not use "MMO", "idle", or "automation" as primary terms until approved for the main game.
- Warning - Public pages using `noindex` should not also be blocked by `robots.txt` if the intended behavior is for search engines to see the noindex directive.
- Decision - The first website SEO pass should prioritize page-specific titles, descriptions, canonical URLs, structured data, sitemap freshness, and crawl clarity before broader keyword testing.
- Decision - The 2026-05-11 page-level SEO pass was deployed to production version `734f5282-affa-43b4-90ec-2f9d36a315c8`.
