# Main Game Content Angles

## Summary

Content for The World Beneath should make the main game readable before asking people to care about every future system.

## Memory Items

- Hypothesis - The strongest content lane is "how the core loop works": dungeon runs feed creature growth, crafting, inventory, and deeper challenges.
- Hypothesis - A second strong lane is "creature identity": monsters, pets, roles, affinities, tiers, upgrades, and team choices.
- Hypothesis - A third lane is "shared world": societies, trade, territory pressure, and world map systems.
- Hypothesis - A fourth lane is "community now": Discord, forum, account identity, lore gateway, and development progress.
- Decision - Landing-page content should prioritize "play World Keys now" once public keys are ready, with book and audiobook as deeper story/lore paths.
- Warning - Do not make the game sound fully live if the public state is still roadmap/account/community/lore plus developing systems.
- Warning - Do not let lore-first copy outrank the first playable World Keys on the public front door.
- Source: [[memory/raw/keyword-research/2026-05-11-main-game-seo-seed-sources]]

## Draft Content Topics

- What is The World Beneath?
- The core loop: dungeons, creatures, crafting, and progression.
- Why creature growth matters.
- How societies will shape the world map.
- What World Keys are, and why they are not the main game.
- Play the first World Keys while you wait for the full game.
- How the book and audiobook connect to the game world.
- What Phase 3 content expansion means.
