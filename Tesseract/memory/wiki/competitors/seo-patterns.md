# SEO Patterns

## Summary

The first SEO pattern is that adjacent games combine a broad genre term with a sharper fantasy, progression model, or mechanic.

## Memory Items

### Main Game

- Signal - Main-game broad lanes include RPG, dungeon crawler, creature collector, crafting, loot, progression, fantasy, party-based RPG, and shared world.
- Signal - Main-game sharper modifiers include creature growth, societies, territory pressure, account identity, hidden world, and community-led worldbuilding.
- Hypothesis - Main-game copy needs at least one concrete RPG mechanic and one world/community differentiator.
- Example: "dungeon RPG" + "creature growth".
- Example: "creature collector" + "shared-world progression".
- Example: "crafting RPG" + "societies and territory pressure".

### Glassroot Garden World Key

- Signal - Glassroot broad lanes include farming, alchemy, idle, automation, relaxing, cozy, management, crafting, simulation, and garden.
- Signal - Glassroot sharper modifiers include occult, dark, magical, Companion/helper automation, alchemical processing, and World Key.
- Hypothesis - Glassroot needs at least one broad lane and one sharp modifier in every major copy surface.
- Example: "idle farming" + "occult alchemy garden".
- Example: "farming sim" + "Companion automation".
- Example: "cozy garden" + "dark World Key atmosphere".
