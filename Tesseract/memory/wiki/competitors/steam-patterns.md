# Steam Patterns

## Summary

Initial Steam pattern scan suggests The World Beneath should pair broad RPG discoverability with specific mechanic/fantasy signals.

## Memory Items

### Main Game

- Signal - IdleOn combines Idler, MMORPG, RPG, Management, Crafting, Resource Management, and community/live-development language.
- Signal - Melvor Idle combines Idler, RPG, Automation, Crafting, Magic, Combat, and Inventory Management tags.
- Signal - Siralim Ultimate combines Creature Collector, Dungeon Crawler, Party-Based RPG, Strategy RPG, Customization, Turn-Based Combat, Procedural Generation, Fantasy, and Loot tags.
- Hypothesis - Main-game store positioning should use concrete system combinations such as "dungeon RPG + creature growth + crafting + shared world".

### Glassroot Garden World Key

- Signal - Strange Horticulture uses occult plant mystery, cozy/dark atmosphere, and plant identification as its clear hook.
- Signal - Potion Craft uses alchemy, tactile ingredient interactions, recipe experimentation, and shop control.
- Signal - Rusty's Retirement uses idle farming, helper automation, and multitasking as core store-page promises.
- Signal - Garden Galaxy uses relaxing garden collection, idler language, and cozy sandbox building.
- Hypothesis - Glassroot should use "farming", "alchemy", "idle", and "automation" for discoverability, then differentiate with "occult garden", "Companions", and "World Key".
