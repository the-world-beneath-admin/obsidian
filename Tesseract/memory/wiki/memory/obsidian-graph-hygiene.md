# Obsidian Graph Hygiene

## Status

Active display policy - created 2026-05-15.

## Purpose

Keep the Obsidian graph useful by showing the durable memory spine rather than every transient report, raw source, task brief, and worker scratch note.

## Default Graph View

The vault graph should hide:

- `memory/short-term/`
- `memory/reports/`
- `memory/raw/`
- `memory/briefs/`
- `templates/`
- orphan notes
- unresolved links

These files still exist and remain searchable. They are hidden from the graph because they are process evidence or working material, not permanent relationship memory.

## Rule

Do not delete worker reports, raw evidence, or task provenance merely to make the graph look cleaner. If a note is durable, promote it into `memory/wiki/` and link it from `memory/index.md`. If it is evidence, keep it in reports/raw/short-term and let the graph filter hide it.

## Memory Items

- Decision - The default Obsidian graph should focus on durable wiki/index memory and hide transient evidence folders.
- Decision - Worker reports and raw sources remain preserved even when hidden from graph view.
- Warning - Graph neatness must not become evidence deletion.
