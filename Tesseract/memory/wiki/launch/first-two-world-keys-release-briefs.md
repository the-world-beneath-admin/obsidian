## Status

Active release planning note - created 2026-05-11.

## Confirmed First Two Free World Keys

1. The Garden
2. The Alchemy Lab

These are the first planned free player-facing World Keys for itch.io release and Kickstarter proof.

## Naming Rule

- Decision - The farming/garden World Key public title is **The Garden**, not **Glassroot Garden**.
- Fact - The player will be asked to name their own garden when they first open The Garden.
- Decision - The second World Key public title is **The Alchemy Lab**.
- Fact - The player will be asked to name their own lab when they first open The Alchemy Lab.
- Warning - Use "Glassroot Garden" only as an internal or historical prototype/source label unless the user later revives it publicly.
- Source: User clarification - 2026-05-11.

## Website Implications

- The homepage can now name the first two World Keys.
- The World Keys page should use cards or sections for The Garden and The Alchemy Lab.
- The copy should stress that players name their own garden/lab, because that gives the experiences personal ownership.
- Avoid making either key sound like the full main game.

## Itch.io Implications

- Each World Key should have a separate itch.io page unless a later publishing decision bundles them.
- The Garden page should not be titled Glassroot Garden.
- The Alchemy Lab page should clearly explain whether it is connected to The Garden or independent.

## Kickstarter Implications

- Campaign proof language can now say the first free World Keys are The Garden and The Alchemy Lab.
- Rewards should not rename or gate these first two free keys.
