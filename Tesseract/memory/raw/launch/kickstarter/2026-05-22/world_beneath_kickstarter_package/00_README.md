# The World Beneath - Kickstarter Funding and Pitch Package

## Start Here

My recommendation is clear:

# Ask Kickstarter for **$150,000**.

That should be the public base goal for Phase One.

This is not a normal "fund my game" campaign. The Kickstarter should be framed as:

> **Help me launch Phase One of The World Beneath: a free proof-of-world web game, Trenchworks as the first paid game reward, the Creator Kit, the living canon archive, the AI coordinator, and the first real community system for a creator-grown IP.**

The Garden web app should be live before the Kickstarter. It becomes proof that the world exists and that you can ship something. It should not be treated as a paid reward.

Trenchworks should become the first paid game/code reward. If Steam is not ready, the reward should promise a digital Trenchworks code with delivery through Steam if available, or through itch.io/direct download as the fallback.

## The Main Strategic Choice

Do not pitch this as an unlimited dream. Pitch it as a concrete Phase One.

**Phase One funds:**

- 12 months of founder runway.
- The Creator Kit.
- The first living canon archive.
- The first AI canon coordinator prototype.
- Trenchworks as the first paid game/code reward.
- Community setup and launch.
- Legal setup for a creator license.
- Equipment, emergency, and operating reserves.

The bigger dream is the living IP. The Kickstarter promise is the seed that makes the dream possible.
