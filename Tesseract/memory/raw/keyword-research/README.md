# Raw Keyword Research

This folder stores raw SEO and keyword research evidence.

## Rule

Raw research is evidence. Do not rewrite it into polished strategy. Summaries and decisions belong in `memory/wiki/marketing/` and `memory/wiki/decisions/seo-decisions.md`.

## What Belongs Here

- Keyword exports
- Steam tag snapshots
- Competitor store-page notes
- Search result observations
- Campaign source data
- Analytics exports
- Creator/channel lists
- SEO tool exports, if added later

## Suggested Filename

```text
YYYY-MM-DD-short-research-topic.md
```
