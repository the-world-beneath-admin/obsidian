## Initial SEO Interpretation

- Signal - The main game should be positioned around shared-world RPG, dungeon runs, creature growth, crafting, inventory, societies, trade, territory pressure, and community identity.
- Signal - World Keys should be described as connected side experiences, not the main game.
- Hypothesis - Strong main-game SEO clusters include shared-world RPG, creature collector RPG, dungeon crawler RPG, crafting RPG, monster collection game, party-based RPG, progression RPG, and community RPG.
- Hypothesis - Idle/incremental language may be useful if the main game foregrounds offline progression or idle systems, but it should not be treated as the core promise until approved.
- Warning - Do not let Glassroot's farming/Alchemy SEO become the main-game SEO.
- Warning - Public marketing should distinguish "live community/account/lore" from "future full gameplay systems."
