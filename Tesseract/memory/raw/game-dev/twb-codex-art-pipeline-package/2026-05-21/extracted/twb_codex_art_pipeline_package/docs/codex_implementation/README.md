# Codex Implementation Pack

## Purpose

These files tell Codex what to actually create in the Unity project.

The art bible explains the style.
This folder explains the implementation.

## Implementation strategy

The first version of the game art should be generated by scripts, not by waiting for perfect image assets.

Codex should create a Unity editor tool that can:

- create the art folder structure
- generate prototype PNG sprites
- import sprites with correct settings
- build prefabs
- create a visual vertical slice scene
- generate simple animation clips
- generate VFX prefabs
- generate UI icons and overlays
- write a report

## Why procedural prototype art

The user needs a usable complete game and has no art skill.

Procedural art lets Codex create:

- consistent colors
- consistent size
- readable silhouettes
- repeatable outputs
- assets that can be replaced later

The result does not need to be perfect.
It needs to be clean, readable, complete-looking, and usable.

## Critical idea

The first art pass is a **locked visual system**, not final art.

Once the system works, better art can replace source images without changing the whole game.
