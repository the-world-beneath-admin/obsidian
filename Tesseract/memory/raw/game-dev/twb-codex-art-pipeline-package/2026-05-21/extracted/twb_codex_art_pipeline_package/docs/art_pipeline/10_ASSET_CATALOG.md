Codex should use this as the checklist.

### Later priority

## 10. Minimum prototype completion condition

The prototype can be called visually complete enough when it has:

- one good biome
- readable trenches
- sandbags
- props
- MG and mortar emplacements
- small helmeted infantry with guns
- at least one vehicle
- muzzle flash / smoke / impact effects
- simple but coherent UI
- simple factory/logistics visuals

At that point the game will no longer look like a broken prototype.
