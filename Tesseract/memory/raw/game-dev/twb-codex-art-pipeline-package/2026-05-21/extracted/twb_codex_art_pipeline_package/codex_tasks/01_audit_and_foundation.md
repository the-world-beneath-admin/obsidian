## Task

Audit the Unity project and create the safe foundation for the TWB art pipeline.

## Requirements

1. Inspect the project structure.
2. Identify Unity version/render pipeline if possible.
3. Do not delete or overwrite existing project content.
4. Create the `Assets/TWB/` folder structure.
5. Create placeholder docs:
   - `Assets/TWB/Docs/ART_PIPELINE_GENERATED_ASSETS.md`
   - `Assets/TWB/Docs/ART_PIPELINE_IMPLEMENTATION_REPORT.md`
6. Create initial editor script stubs if needed:
   - `TwbPrototypeArtGeneratorWindow.cs`
   - `TwbPrototypeArtGenerator.cs`
   - `TwbSpriteImportUtility.cs`
   - `TwbTextureDrawUtility.cs`
7. Add a menu item:
   - `TWB/Art Pipeline/Generate Prototype Art`

## Done when

- Unity compiles.
- Folders exist.
- The menu item exists.
- Existing project files are not harmed.
- The implementation report includes the audit summary.
