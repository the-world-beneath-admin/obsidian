# UI and Icon Style

## Purpose

A complete-looking game needs UI that matches the world.

Even simple battlefield art will look better if the UI is clean and consistent.

## 1. UI style goals

The UI should feel:

- military
- practical
- readable
- slightly worn
- organized
- not futuristic glossy
- not fantasy ornate

## 2. Panel style

### Recommended panel look

- muted dark backing
- metal / canvas / field-manual influence
- subtle bevel or edge wear
- clean borders
- clear sectioning

### Avoid

- neon sci-fi panels
- overly modern phone-app style
- noisy background textures behind text

## 3. Icon categories

### Core icons

- infantry
- engineer
- MG
- mortar
- truck
- tank
- ammo
- fuel
- supplies
- build
- repair
- attack
- defend
- factory
- trench
- bunker
- upgrade

### Resource icons

- ammo crate
- shell
- fuel can
- parts
- manpower
- food/rations if used

## 4. Icon design rules

Icons should be:

- silhouette-first
- simple
- readable at small size
- consistent stroke and shading style
- easy to color-code if needed

Do not render ultra-detailed item illustrations.

## 5. Selection and state visuals

### Use simple clear indicators

- selected unit ring
- hovered outline
- build ghost
- damaged indicator
- suppressed / alerted state if used
- production progress bar
- cooldown or reload bar

These are cheap to make and strongly improve clarity.

## 6. Minimap / tactical overlay style

If a minimap exists:

- use simplified shapes
- clear faction colors
- easy trench readability
- building icons and unit blips
- avoid visual clutter

## 7. Menu art rules

Main menus and overlays do not need giant original illustrations.

Use:

- cropped battlefield diorama scenes
- clean emblem graphics
- trench silhouettes
- simple industrial / wartime framing

Keep effort focused on the gameplay art first.

## 8. Typography guidance

Codex should use a readable utilitarian UI font.

The font should feel:

- practical
- clean
- slightly military or technical
- never gimmicky

Keep text clarity above theme.

## 9. What UI should look like

The UI should feel like a field command interface for a trench logistics war simulation.

It should support the game, not fight the player.

Good UI will make even modest art look more serious and complete.
