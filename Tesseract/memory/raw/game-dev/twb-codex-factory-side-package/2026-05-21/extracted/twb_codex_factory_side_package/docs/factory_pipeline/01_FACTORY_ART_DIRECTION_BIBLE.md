# Factory Art Direction Bible

## Purpose

This document defines what the factory/logistics side should look like.

It must match the trench battlefield side while having its own identity.

---

## 1. Visual target

The factory side should look like a top-down 2.5D wartime production yard.

It should communicate:

- practical military industry
- rough field manufacturing
- supply pressure
- functional machines
- dirt, oil, metal, wood, crates, pipes, smoke
- clear automation routes

It should not look like shiny sci-fi automation.
It should not look like a direct copy of any existing factory game.

---

## 2. Camera assumptions

- top-down orthographic or near-orthographic
- slight 2.5D depth only for readability
- no strong perspective
- machine tops should be readable
- object height implied through edges and shadows

---

## 3. Factory style pillars

### Readability
The player must instantly read machine type, logistics direction, item identity, and blocked states.

### Modularity
Machines, belts, pipes, floors, and props must be assembled from reusable parts.

### Wartime function
Everything should feel practical and tied to war production.

### Consistency
The factory side must fit the battlefield side's palette, lighting, and silhouette discipline.

### Completion over detail
A simple complete factory is better than two beautiful machines and no working chain.

---

## 4. Color direction

### Base colors
- compacted mud brown
- industrial gray
- olive drab
- khaki canvas
- dark rubber
- dull brass/copper accents
- muted steel blue-gray
- weathered wood

### Accent colors
Use sparingly:

- small status lamps
- faction markings
- direction arrows
- warning stripes
- selected object highlights
- power/blocked indicators

### Avoid
- neon sci-fi colors
- glossy modern factory look
- oversaturated toy colors
- heavy rainbow resource coding unless UI requires it

---

## 5. Lighting

Use same lighting assumption as the battlefield side:

- upper-left primary light
- soft lower-right shadows
- contact shadows under machines
- slightly brighter top planes
- darker machine sides

Do not use inconsistent light directions between factory and battlefield assets.

---

## 6. Surface treatment

### Factory floor
- compacted dirt
- worn concrete patches if used
- tire scuffs
- oil stains
- belt/worker traffic wear
- subtle grid readability

### Machines
- matte metal
- worn paint
- simple panels
- pipes and vents
- clear input/output sides
- top-down readable silhouette

### Belts
- dark rubber or canvas belt
- metal rollers or side rails
- visible direction marker or animation
- items should stand out on belt surface

### Pipes
- dull metal
- elbows/flanges/valves
- fluid color only where needed
- simple direction or connection clarity

---

## 7. Silhouette language

### Extractor
Should look like it is pulling material from the ground:

- drill head / scoop / pump element
- anchored base
- output chute
- resource patch underneath or nearby

### Processor
Should look like it transforms raw material:

- furnace/press/mill body
- vent/smoke stack
- input and output ports
- working animation location

### Workshop / assembler
Should look like it combines parts:

- broader workbench body
- visible mechanical arm or tool head
- crate output area
- optional gear/press graphic

### Depot
Should look like storage and dispatch:

- crate stacks
- loading platform
- sign/marker
- open input area
- clear output-to-frontline identity

---

## 8. Detail level

Use large readable details:

- vents
- hatches
- belts
- bins
- pipes
- handles
- status lights
- small warning stripes

Avoid tiny detail that turns into noise:

- hundreds of bolts
- complex gauges
- small unreadable labels
- realistic engine interiors

---

## 9. Animation identity

The factory should feel alive through simple loops:

- belt scrolling
- item movement
- machine bob/press cycle
- fan rotation
- smoke puff
- sparks
- depot pulse when output delivered

Animation should be cheap and clear.

---

## 10. What complete looks like

A complete factory scene should show:

- where resources come from
- where items move
- which machines work
- which machines are blocked
- which outputs feed the war
- why the player should build more

The game can look basic and still feel finished if these are clear.

---

## Final visual sentence

The factory side should look like a compact, readable, wartime industrial yard where belts, pipes, machines, and depots visibly produce supplies for the trench front.
