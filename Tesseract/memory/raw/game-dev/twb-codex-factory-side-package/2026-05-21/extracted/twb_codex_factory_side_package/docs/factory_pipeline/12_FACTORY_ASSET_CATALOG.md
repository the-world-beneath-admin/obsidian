# Factory Asset Catalog

## Purpose

This is the minimum viable asset list for the factory/logistics side.

---

## 1. Floors and terrain

### Required
- compacted dirt yard tile
- worn concrete pad tile
- loading pad tile
- metal floor plate tile
- ore patch
- scrap patch
- oil stain decal
- tire mark decal
- scrap debris decal
- build grid overlay

### Optional
- road tile
- rail/track tile
- damaged floor tile
- puddle decal

---

## 2. Logistics

### Belts
- straight horizontal
- straight vertical
- corner NE
- corner SE
- corner SW
- corner NW
- input/output cap
- splitter optional

### Pipes
- straight horizontal
- straight vertical
- corner elbows
- T-junction optional
- valve optional
- pump optional

### Ports
- input port marker
- output port marker
- blocked port warning

---

## 3. Machines

### Required
- extractor
- processor
- workshop / assembler
- storage depot
- frontline supply depot
- generator
- power pole or power marker

### Optional
- refinery
- ammo press
- sandbag filler
- fuel processor
- repair bench
- shell foundry

---

## 4. Items

### Required first chain
- ore chunk
- metal parts
- ammo crate

### Recommended expansion
- sandbag kit
- shell crate
- fuel can
- repair parts
- cloth bundle
- explosive charge
- casing
- generic supplies

---

## 5. VFX

### Required
- smoke puff
- dust puff
- spark flicker
- output pulse
- machine working pulse
- generator smoke
- placement highlight

### Optional
- pipe leak
- small steam vent
- depot dispatch effect
- belt jam marker

---

## 6. UI/icons

### Required
- build icon: belt
- build icon: extractor
- build icon: processor
- build icon: workshop
- build icon: depot
- build icon: generator
- status: working
- status: missing input
- status: blocked output
- status: no power
- item icons for core items

---

## 7. First vertical slice minimum

The first scene must include:

- ore patch
- extractor
- belt path
- processor
- workshop
- depot
- generator
- ammo crate output
- frontline supply counter

If these are present and working, the factory side is ready for gameplay iteration.
