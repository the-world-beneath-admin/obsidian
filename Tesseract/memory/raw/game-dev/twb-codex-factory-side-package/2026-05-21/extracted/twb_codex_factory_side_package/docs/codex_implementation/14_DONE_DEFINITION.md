# Done Definition

## Factory side is not done when

- only documents exist
- only empty folders exist
- only one pretty machine exists
- belts are static decoration only
- machines do not produce anything
- UI does not explain stopped machines
- output does not connect to a supply counter

---

## Factory side is minimally done when

A player can open the vertical slice and see:

1. a resource patch
2. an extractor producing ore
3. ore moving on belts
4. a processor making metal parts
5. metal parts moving on belts
6. a workshop making ammo crates
7. ammo crates moving to a supply depot
8. a supply counter increasing
9. machines showing working/stopped states
10. visuals that look consistent and readable

---

## Visual done threshold

The factory art is done enough when:

- machines are recognizable
- belt direction is clear
- item tokens are readable
- status warnings are readable
- the floor is not empty/ugly
- the whole scene feels intentionally styled

---

## Gameplay done threshold

The factory gameplay is done enough when:

- recipes are data-driven
- one chain works reliably
- output can feed battlefield supply
- blocked/missing/no-power states are handled

---

## Expansion allowed after done

Only after the first chain is done should Codex add:

- more recipes
- more machines
- more resources
- more belts/pipes complexity
- deeper power/fluid systems
- more factory polish
