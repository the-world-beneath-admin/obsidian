# Task 08 — Validation and Polish Report

## Goal

Verify the factory side is usable and document what remains.

---

## Validation checklist

Codex should check:

- no compiler errors
- no missing scripts on prefabs
- generated sprites exist
- vertical slice scene opens
- placement works
- belts move items
- machines process recipes
- status UI updates
- frontline supply output increments
- art is readable at gameplay zoom

---

## Polish pass

If time remains, improve:

- icon clarity
- belt animation readability
- machine status overlays
- placement ghost clarity
- depot output feedback
- factory floor decals

---

## Required report

Create:

```text
Assets/TWB/Factory/Docs/factory_validation_report.md
```

Include:

- systems implemented
- files created
- scene name
- how to test
- known problems
- recommended next steps

---

## Acceptance criteria

This task is complete when:

- the report exists
- key systems have been tested or honestly marked untested
- the factory side has a clear next step list
