# Visual Recipe Details

## Purpose

This document gives Codex concrete visual recipes for generated prototype art.

---

## 1. Compacted dirt yard tile

### Should include
- brown/gray muddy base
- subtle speckles
- tire or foot wear
- not too much contrast

### Should not include
- strong grid lines baked in
- huge rocks blocking placement
- bright colors

---

## 2. Worn concrete pad

### Should include
- dull gray slab
- cracks/scuffs
- light dirt overlay
- slightly darker edge

### Use
Under heavier machines or depots.

---

## 3. Ore patch

### Should include
- clustered dark ore chunks
- dirt depression
- irregular shape
- clear enough to locate

### Use
Extractor placement target.

---

## 4. Belt segment

### Should include
- dark belt strip
- metal side rails
- direction chevrons or arrows
- slight highlight/shadow

### Must read as
A conveyor belt moving goods.

---

## 5. Pipe segment

### Should include
- metal tube
- flange ends
- darker underside
- elbow variants

### Must read as
A pipe network, not a road or cable.

---

## 6. Extractor

### Shape
- 2x2 footprint
- square/rectangular base
- drill/scoop/pump head
- output chute on one side

### Details
- dust/spark area
- status lamp
- contact shadow

### Must read as
A machine pulling raw material from the ground.

---

## 7. Processor

### Shape
- 2x2 or 3x2 footprint
- heavy metal body
- vent/smokestack
- press/furnace/crusher symbol

### Details
- input port
- output port
- smoke/spark VFX point

### Must read as
A machine transforming raw goods into parts.

---

## 8. Workshop / assembler

### Shape
- 3x2 footprint
- broad workbench body
- tool arm or press head
- output platform

### Details
- small crate pad
- moving tool cue
- status lamp

### Must read as
A machine making finished supplies.

---

## 9. Storage depot

### Shape
- 3x3 footprint
- platform base
- stacked crates
- loading area

### Details
- input/output edge
- optional count indicator when selected

### Must read as
A storage and buffering area.

---

## 10. Frontline supply depot

### Shape
- 4x3 footprint recommended
- larger loading dock
- military supply crates
- route/frontline marker

### Details
- output pulse
- truck/road cue optional
- supply icon marker

### Must read as
The factory output link to the war front.

---

## 11. Generator

### Shape
- 2x2 footprint
- engine body
- fan/vent
- smoke stack
- fuel tank/can cue

### Details
- smoke loop
- power radius overlay when selected

### Must read as
A power source.

---

## 12. Item tokens

### ore_chunk
Irregular dark rock/ore cluster.

### metal_parts
Small plate/gear/parts bundle.

### ammo_crate
Military crate with simple ammunition cue.

### sandbag_kit
Bundle of sandbags or tied sack stack.

### fuel_can
Small canister shape.

### repair_parts
Tool/gear bundle.

### shell_crate
Crate with shell silhouettes.

---

## 13. Status icons

### working
Gear/lamp/check-like symbol.

### missing input
Crate with question or empty input marker.

### output blocked
Box/stop/jam symbol.

### no power
Lightning warning symbol.

### storage full
Stacked crate/full marker.

Keep icons simple and readable.
