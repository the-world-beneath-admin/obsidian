# Task 07 — Factory Vertical Slice

## Goal

Create one complete playable demo scene for the factory side.

---

## Scene name

Create or update:

```text
Assets/TWB/Factory/Scenes/FactoryVerticalSlice.unity
```

If project conventions require a different location, use the closest equivalent and document it.

---

## Scene contents

The scene should include:

- factory floor / yard
- resource patch
- extractor
- belts
- processor
- workshop / assembler
- storage depot
- supply depot
- power source
- build menu
- selection UI
- item tokens moving
- machine status feedback
- production counter

---

## Demo goal

The player should be able to produce at least one frontline supply resource.

Example:

```text
produce 10 ammo crates for the front
```

---

## Acceptance criteria

This task is complete when:

- the scene opens without errors
- the production chain works end-to-end
- factory visuals are readable
- the UI explains what is happening
- the output depot produces a measurable frontline supply result
