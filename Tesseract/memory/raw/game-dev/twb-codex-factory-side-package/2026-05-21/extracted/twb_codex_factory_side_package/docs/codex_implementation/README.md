# Codex Implementation README

## Purpose

This folder tells Codex how to implement the factory side in Unity.

The goal is not only to define art direction. The goal is to produce working systems, prefabs, generated art, and a vertical slice scene.

---

## Implementation target

Codex should build:

- generated factory art utility
- grid placement
- belts/items
- machines/recipes
- power/status feedback
- UI panels
- frontline supply bridge
- vertical slice scene

## Coding philosophy

Make the simplest complete system first.
Use readable code.
Use data definitions.
Avoid over-simulation.
Make the game work before expanding complexity.
