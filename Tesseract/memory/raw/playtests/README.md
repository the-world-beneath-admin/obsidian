# Raw Playtests

This folder stores raw playtest evidence for World Key: Glassroot Garden.

## Rule

Raw notes are evidence. Do not rewrite them into polished memory. Summaries belong in `memory/wiki/playtesting/`.

## What Belongs Here

- Live observation notes
- Player quotes
- Session transcripts
- Screenshots
- Video links or recording notes
- Tester profile notes
- Build/version notes

## Suggested Filename

```text
YYYY-MM-DD-playtest-player-or-session-name.md
```
