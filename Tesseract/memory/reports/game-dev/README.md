# Game Dev Reports

Game-dev reports are working evidence, not permanent memory.

Specialists write reports here after bounded game development, debugging, tuning, or implementation tasks. The orchestrator reviews reports and decides what, if anything, becomes permanent memory in `memory/wiki/`.

## Naming

Use:

```text
YYYY-MM-DD-short-task-name.md
```

Example:

```text
2026-05-11-bundler-recipe-validation.md
```

## Required Format

```markdown
# Game Dev Report - YYYY-MM-DD - Short Task Name

## Task

What was requested.

## Result

What changed or was learned.

## Files Touched

- TBD

## Checks Run

- TBD

## Risks

- TBD

## Memory-Worthy Notes

- TBD

## Do Not Promote To Memory

- TBD

## Follow-Up Recommendations

- TBD
```

## Promotion Rule

Do not treat a report as permanent truth. Promote only reviewed, stable items into the wiki using the labels Fact, Decision, Signal, Hypothesis, Warning, Open Question, or Superseded.
